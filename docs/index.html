Run My Agents

Run many Claude Code sessions on one repo, and stop them overwriting each other's work.

In Claude Code
> /plugin marketplace add flisk-sh/run-my-agents
> /plugin install run-my-agents@run-my-agents

No server. No account. No keys. Everything stays on your computer.

What your agent sees

Session 2 tries to edit a file session 1 changed two minutes ago.

session 1 · Edit api.ts ✓
session 2 · Edit api.ts
⚠ Another Claude session (9d5f2846 on branch fix-login) edited api.ts 2 min ago.
  Read the file again first, or work on a different file.
session 2 · Read api.ts, then Edit api.ts ✓ nothing lost

How it works

One small hook. A warning, not a lock.

01

Every edit is noted

Before Claude edits a file, the hook writes down which session touched it.

02

Overlaps get a warning

If another session edited that file in the last 10 minutes, the edit stops once, with a note.

03

The agent carries on

It re-reads the file and edits again. A second try always goes through.

What it doesn't do yet

  • It only sees sessions on this computer.
  • It doesn't see edits made through shell commands like sed.
  • It matches whole files, not lines.
